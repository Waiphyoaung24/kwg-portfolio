# Source attribution

UI styling uses daisyUI 5 (MIT licensed, https://github.com/saadeghi/daisyui) as a Tailwind CSS plugin, pinned by package-lock.json. The dashboard's `kwg` theme is original. No shadcn/ui, Radix UI or Base UI code remains.

The nine empty productivity templates are adapted from the user's Wai-G Obsidian template structure: https://github.com/kyawcthu/Wai-G-Obsidian-Template . No reference archive scripts, plugin configuration, or example records are executed or imported. The goals, niche, conversation, lead and quarterly templates are original.

Motion references retained from the source dashboard are AI CSS Animations pushable-button, card-lift, and link-underline examples: https://www.aicssanimations.com/directory . The portfolio variant removes shadows and colored chrome, uses subtle hover/focus transitions, and respects reduced motion.
